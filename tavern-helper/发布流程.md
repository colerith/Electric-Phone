# 电波手机扩展发布流程

当前版本：1.3.0。

1. 修改 `manifest.json`、`package.json`、`tavern-helper/电波手机/schemas.ts` 和版本记录；不要因普通发布修改存储版本。
2. 在独立仓库运行 `pnpm install`、`pnpm build`、`pnpm test:extension`。原工作区可运行 `pnpm exec webpack --config wave-extension.webpack.cjs`，复制 `dist/wave-extension/index.js` 与 LICENSE 到仓库 `dist/`。
3. 检查源码、文档、manifest 与构建版本一致。提交明确列出的文件，创建版本标签并原子推送 main 与标签。
4. 安装检查：仓库根 manifest 的 `js` 为 `dist/index.js`；普通用户通过酒馆扩展管理更新，刷新生效。
5. 保留 `file/index-1.2.43.js` 作为最后的旧脚本版本，历史标签不覆盖。扩展产物不使用旧脚本 import 路径。
6. 迁移测试覆盖旧脚本重复运行拦截、私有变量复制、全局/聊天数据保持、当前上下文更新、事件清理及缺少助手时的恢复入口。

仍需保留真实酒馆端人工验收记录；自动化模拟环境不能替代真实生成、音乐扫码及会员账号验收。
