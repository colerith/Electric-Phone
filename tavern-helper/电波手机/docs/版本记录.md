# 版本记录

## 1.1.33

- 收紧版权与致谢卡片中英文眉题与中文标题的间距，并用设置页高优先级样式阻断酒馆主题干扰。
- 日历天气城市改为按当前角色独立保存，切换角色时同步切换地点；旧版全局城市会自动迁移给当前角色。
- 天气卡片移除“降水”，改为展示 Open-Meteo 当前天气接口的“体感温度”。
- 私聊时的“使用日历城市”也改为读取当前角色对应的日历地点。

## 1.1.32

- “版权声明”和“鸣谢清单”改用设置页内置标题样式，阻断酒馆主题对标题标签的装饰影响。
- 版权来源中将完整的“日月西 TA的手机”作为加粗内容。
- 免费开源小手机鸣谢清单新增“柏柏小手机”。

## 1.1.31

- 对外 README 重写为电波手机使用指南，按消息、状态、备忘、空间、钱包、日历、浏览和音乐分模块说明。
- 使用指南补充安装、首次配置、生成同步、数据备份、隐私和常见问题。
- 设置中新增“版权与致谢”模块，集中展示原创与基础来源声明、允许范围、禁止事项和鸣谢清单。
- 鸣谢页加入柏柏音乐播放器的 Discord 参考链接，并适配手机宽度与明暗主题。

## 1.1.30

- 空间评论头像固定为等宽高圆形，修复酒馆样式影响下被拉成椭圆的问题。
- 评论作者缺少用户或联系人头像时，按稳定身份种子补充随机头像，同一作者重复出现时保持一致。
- 打通 DiceBear Notionists 与 Bottts Neutral 两套空间头像库；匿名树洞用户、NPC、动态作者和评论作者都会从合并头像池中稳定随机取图。
- 空间手动生成期间，灵动岛由“朋友圈生成中”更正为“空间生成中”。

## 1.1.29

- 跟随酒馆生成的手机提示改为前置内部上下文，并在落盘前清理意外回显，避免原生提示词进入正文。
- 手机聊天连续性记录扩充为最近 24 条，并纳入跟随生成的手机消息，帮助酒馆正文承接已知信息、约定与关系变化。
- Ecot 折叠与隐藏只作用于手机消息和应用，不再注册酒馆楼层渲染，也不改写酒馆的 Ecot 正则行为。
- 世界动态允许同轮返回场景 NPC 与陌生人两份资料，修复 `npcs` 数组超过 1 项时的校验失败。
- 隐藏酒馆楼层时仍重放其中的手机数据，避免钱包与空间被清空；独立生成内容继续保留。
- 红点只在新增或变化的手机数据出现时触发，不再把楼层隐藏、删除或快照归一化误判为新内容。

## 1.1.28

- 发红包弹窗移除红包状态与已抢个数选择；用户发送的私聊红包固定从未收款开始，群聊红包固定从待抢、0 人领取开始，后续状态交由角色互动推进。

## 1.1.27

- P1 树洞与 P2 编辑资料的输入控件补充样式隔离，避免酒馆主题覆盖；P3 消息页不再同步展示空间称号和徽章。
- 备忘与涂鸦的删除按钮统一移至卡片右下角。
- P2 输入扩展菜单移除通话并新增红包；支持用户与角色红包气泡、未收款/已收款/已退回状态，以及群聊抢红包明细。
- 私聊与群聊生成协议、上下文和提示词加入红包格式与状态约束，角色可依据情境低概率主动发送红包。
- 设置页“导入内置标签”的排除列表新增 `snow`。

## 1.1.26

- 更多表情使用统一描边的笑脸加号图标。
- 角色可对当前线程的用户消息贴表情，私聊与正文增量协议加入可选 reactions；按真实消息 ID 与成员身份校验，重放不重复。
- 提示词要求默认不贴、仅情绪合适时偶尔贴，每轮最多一个，已有反应进入上下文以避免滥用。
- 无图照片的描述在灰色画面区域居中显示；真实图片无描述时不再显示“一张照片”占位，兼容旧消息。

## 1.1.25

- 对方消息的长按/右键菜单新增六个快捷反应和完整 Emoji 分类面板，最近使用自动置前。
- 反应贴在对应消息下，点击可取消；最多同时贴六种，按聊天与消息持久化，转发不复制反应。
- 消息操作框缩窄为 278px，减少按钮高度、间距、图标与圆角尺寸。

## 1.1.24

- 编辑资料新增随机匿名头像和美食组合昵称，支持分别换一组，保存后跨聊天沿用；旧的匿名发言与评论同步显示该身份。
