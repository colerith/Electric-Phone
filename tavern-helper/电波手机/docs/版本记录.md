# 版本记录

## 1.1.25

- 对方消息的长按/右键菜单新增六个快捷反应和完整 Emoji 分类面板，最近使用自动置前。
- 反应贴在对应消息下，点击可取消；最多同时贴六种，按聊天与消息持久化，转发不复制反应。
- 消息操作框缩窄为 278px，减少按钮高度、间距、图标与圆角尺寸。

## 1.1.24

- 动态头像与昵称间距加宽，昵称下显示灰色 @账号；树洞统一正文、底部时间与操作栏布局，不展示账号。
- 徽章分类使用隔离的内置标题样式，避免外部标题装饰干扰。
- 编辑资料新增随机匿名头像和美食组合昵称，支持分别换一组，保存后跨聊天沿用；旧的匿名发言与评论同步显示该身份。

## 1.1.23

- 角色空间和我的主页按钮统一底色、文字色、图标色、字号和圆角。
- 徽章改为八类纵向分组，搜索结果仍保留分类标题，修复搜索框与分类挤压。
- 动态删除入口改为粉色，增加取消优先的确认弹窗；切换聊天时关闭待确认操作。
- 匿名树洞可删除动态及其互动，头像固定圆形；使用 DiceBear Bottts Neutral 随机头像，同一天自己的发言与回复头像一致，失败时显示本地机器人图标。
- 私聊表情包搜索框输入和占位文字缩小为 12px。

## 1.1.22

- 称号提供 10 个通透色块，文字固定白色；缩小主页徽章，保留旧选择。
- 彩色徽章加入 Microsoft Fluent Emoji Flat，扩充为 160 枚、8 个分类，支持搜索；图标与 MIT 许可随包发布。
- 角色主页默认文案与个签字号一致，私聊和更新动态按钮补充图标。
- 发布页、输入区、顶部状态栏与底部安全区域统一白色沉浸配色。
- 动态支持回车添加与删除蓝色 #话题，去重并限制最多 8 个；中文输入法选字不会误提交。
- 角色空间与世界动态生成协议补充 tags，旧动态补评论时保留原有标签，显式空数组可清除标签。

## 1.1.21

- 恢复空间封面个人卡片、独立圆角动态、日记筛选与搜索；角色、世界、树洞、我的底栏统一高度并避开小白条。
- 发布页编辑区域填满剩余高度，保留短屏滚动；参与者和概率节奏设置统一卡片外框。
- 动态、旧空间评论及匿名树洞评论保留双语，译文紧随正文自然展示；同步私聊翻译与展开偏好。
- 场景 NPC 与陌生网友使用独立参与开关，陌生人仅参与可见内容，身份与人设可跨轮复用。
- 个人主页账号显示 @账号，新增自定义称号、颜色与最多 4 枚分类彩色徽章；内置 40 枚 Noto Emoji SVG 并保留授权。
- 角色资料生成协议同步称号、颜色、徽章字段；旧自定义提示词也会附加当前结构协议。
- 增加徽章存储、陌生人范围、评论译文、生成协议测试，并验证完整手机容器内的布局。

## 1.1.20

- 空间统一角色动态、世界动态、发布、每日匿名树洞与个人主页；消息应用保留消息、联系人、我的资料与钱包。
- 原朋友圈互动配置迁入空间设置，个人主页可筛选发布、喜欢、评论，并统计收到的喜欢。
- 旧空间动态及点赞、评论继续显示；评论采用头像、姓名、时间和 @ 回复样式。
- 同一角色卡的账户、余额、流水、币种、银行资料、账户选择及空间/钱包封面跨 chat 共享，旧 chat 首次迁移并隔离楼层来源。
- 备份加入共享账本与封面；跨聊天切换、重复同步和旧数据迁移具备回归验证。
- 修复封面卡片标题间距，源码按组件、服务、样式的功能目录组织。

树洞是角色扮演内的本地匿名功能，参与者发言可通过现有副 API 生成，不是联网公共社区。
