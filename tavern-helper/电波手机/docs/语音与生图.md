# 语音与生图（1.1.72）

## Fish 鱼声

在「设置 → 语音与媒体」启用 Fish，填写密钥、模型和可选代理根地址并保存；到私聊设置的「角色语音」选择 Fish 和音色 Voice ID。

模型列表从官方 `https://api.fish.audio/openapi.json` 的 `/v1/tts` 模型请求头枚举读取，补齐 s1、s2-pro、s2.1-pro、s2.1-pro-free、Drama 3（实际 ID `drama-3-preview`）。Fish `/model` 返回的是音色库，不用作引擎列表。刷新失败保留内置模型，也可手动填写 ID。

## 生图 API

1. 打开「设置 → 图像生成」，添加 NovelAI 或 GPT Image 配置。
2. 填写密钥和地址；留空地址使用官方服务。可以保留多套配置，独立选择模型、画幅与参数。
3. 「拉取模型列表」尝试接口列表；NovelAI 官方列表目前返回 404，保留内置 NAI V5 curated/full 和 4.5。GPT Image 支持 `/v1/models` 拉取，并内置当前文档列出的 2.5 Sunburst / Flare 等模型。模型 ID 可手动填写，实际可用性以服务端权限为准。
4. 进入私聊设置的「角色生图」，或点击输入栏「＋ → 生图」，启用当前角色、选择接口、填写固定外貌并添加参考图。
5. 填写本次画面描述，点击「生成并发到私聊」。只在点击时生成，不在载入页面或角色回复时自动计费。成功图片会作为角色图片消息保存。

NovelAI 参考图按模型通过 `/ai/encode-vibe` 编码，已有匹配 Vibe 编码会直接复用；GPT Image 有参考图时走 `/v1/images/edits`，没有时走 `/v1/images/generations`。仅有 Vibe 编码而没有原图的参考不能用于 GPT Image。每角色最多 8 张参考图。

关闭生成面板或切换聊天会取消请求；若原会话已清空，迟到的结果不会写入其他会话。取消不能保证服务端停止计费。单次请求最多等待 4 分钟。

## NovelAI Vibe 配置

在每套 NovelAI 配置底部的「Vibe 参考」添加图片、导入官方 .naiv4vibe 文件，或从柏宝绘选择参考图。每张可独立启停、改名、调整参考强度和信息提取度。仅有编码且无原图的文件，信息提取度随编码固定；有原图时，改变提取度会重新编码。

接口 Vibe 与角色参考图在生成时合并，同一来源 ID 去重，合计最多启用 8 张；关闭或强度为 0 的参考不会发送。归一化开启时，总强度超过 1 会按比例缩放。Vibe 随「通用与 API 设置」备份；重复读取柏宝绘接口参数会保留手机配置里的 Vibe。

## 柏宝绘兼容

- 「读取柏宝绘配置」只读导入已保存的 NovelAI 接入点、模型、竖屏尺寸、采样参数与当前画风；重复导入按来源 ID 更新，不改写柏宝绘自身设置。
- 私聊「读取柏宝绘角色 / 参考图」读取 `STBaiBaiImage.getCharacters()` 公开角色库，选择档案后导入外貌。旧插件若没有此接口，请更新柏宝绘或手工填写。
- 参考图可从柏宝绘服务器文件或本地 IndexedDB 复制到手机资料，保留原图与不同模型的编码；按用户选择导入，不把全局参考图库自动套到角色上。
- 全局 API 配置属于备份的「通用与 API 设置」；角色生图开关、外貌、参考图属于「消息设置＋角色设定」；成品图片属于「聊天记录」。跨设备迁移请同时选择相关模块。

## 私聊音色收藏与生图分块（1.1.73）

在角色语音中填写服务和 Voice ID，再填写备注并点击「保存当前音色」。已保存音色下拉可随时切换，选择时会一并切换对应服务；删除收藏不会清空当前音色。列表随该角色资料保存与备份，旧版单个 Voice ID 继续生效。

私聊生图按「角色生图接口、角色外貌、参考图、本次生成」分成四张卡片。普通标签、输入内容、帮助文字使用正常字重，与其他设置页保持一致。

私聊输入栏「＋ → 刷新」现在通过独立 API 重新生成最近一轮已有回复。原用户消息与草稿保留，新回复成功后才替换，失败或取消保留原回复；不会重复更新钱包和其他应用。请先在「设置 → API 连接」配好独立 API。
