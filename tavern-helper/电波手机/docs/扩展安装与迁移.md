# 电波手机扩展安装与迁移

从 v1.3.0 开始主发布形式为 SillyTavern 前端扩展，参考 [StageDog/tavern_extension_template](https://github.com/StageDog/tavern_extension_template) 的 manifest 与安装目录约定。保留既有 Vue 组件，不重写应用数据结构。

## 安装

1. 酒馆需为 1.13.0 或更新版本，并安装、启用酒馆助手 4.x。扩展继续使用酒馆助手的变量、生成、世界书和正则接口。
2. 在旧电波手机中导出一份备份；在酒馆助手停用旧电波手机脚本，保留其数据。无需删除脚本，也不要同时运行两份。
3. 酒馆「扩展 → 安装扩展」填写 `https://github.com/colerith/Electric-Phone`，安装后刷新页面。
4. 从酒馆扩展菜单「电波手机」进入，或在扩展设置区点击「打开电波手机 / 重试」。已有悬浮球设置继续生效。
5. 以后在酒馆扩展管理中更新，再刷新页面。不再修改脚本 import 地址。

手动安装可把仓库克隆到 `SillyTavern/public/scripts/extensions/third-party/Electric-Phone`（全用户），或对应用户的 `data/<用户名>/extensions/Electric-Phone`（仅该用户）。不要两处重复安装。仓库已带构建产物，普通用户无需 Node/pnpm 构建。

## 数据衔接

- 沿用 `wave_phone_durable_v1`、全局/聊天变量以及原服务器 `wave-phone-v1-*.json` 双槽文件。`WAVE_PHONE_STORAGE_VERSION` 不变，不初始化覆盖已有存档。
- 老脚本私有变量迁入 `wave_phone_extension` 扩展变量；只在识别到唯一旧电波脚本时复制 `wave_phone*` 键，不修改原脚本，不清理其他插件数据。
- 多份旧脚本有不同私有数据时不猜测覆盖；主要存档仍按原有服务器/聊天存储读取，需要时从选定旧脚本导出再导入备份。
- 设备电量使用扩展变量保存。音乐账号仍使用同一酒馆来源的浏览器本地存储。
- 启动发现旧脚本仍启用或已存在手机界面时，暂停扩展启动，提示停用旧脚本后重试。扩展设置中的恢复入口始终保留。

## 运行与构建

扩展在酒馆主页面运行，直接挂载界面。Vue、Pinia、Zod、OpenCC 等打入安装包；jQuery、toastr 使用酒馆提供的实例。酒馆助手函数通过构建时的局部绑定调用 `window.TavernHelper`；当前聊天上下文每次从 `SillyTavern.getContext()` 读取，不把快照当成永久上下文，也不覆盖全局 `SillyTavern` 或其他插件函数。

独立仓库根目录执行：

```sh
pnpm install
pnpm build
pnpm test:extension
```

需要 Node 22+；产物是 `dist/index.js` 和 `dist/index.js.LICENSE.txt`。样式随 JS 挂载，manifest 无需额外 CSS 文件。源码暂保留在 `tavern-helper/电波手机`，共享逻辑仍可在原工作区运行脚本回归测试。

在原脚本工作区执行 `pnpm exec webpack --config wave-extension.webpack.cjs`，产物位于 `dist/wave-extension`。

## 音乐后端边界

这个模板是前端扩展模板。前端扩展不能在浏览器里启动 Node 服务，也不会因为安装为扩展就自动获得 QQ/网易云/酷狗后端。v1.3.0 保留已有三家 API 地址配置；接入方法见 [音乐账号接入](音乐账号接入.md)。若以后内置音乐服务，需要另外实现 SillyTavern 服务端插件及其安装、依赖、账号存储与升级流程。

## 回退

停用扩展并刷新，然后重新启用旧 v1.2.43 脚本。不要同时启用扩展与脚本。现有服务器/聊天存档格式兼容；迁移不会删除原脚本数据。回退前可再导出当前备份。
