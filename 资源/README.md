## 建议后续目录

```text
资源/
├─ UI参考图/       # 原始交互与视觉参考
├─ 字体/           # 经许可使用的 WOFF2 字体及许可证
├─ 图标/           # SVG 图标与图标规范
├─ 壁纸/           # 锁屏、桌面与聊天壁纸
├─ 音效/           # 通知、发送、来电等短音频
├─ 小组件/         # 小组件背景或预览素材
├─ 主题预设/       # 主题 manifest、token 与缩略图
└─ 示例数据/       # 无敏感信息的角色卡、世界书、Preset 示例
```

## 使用约束

- 例图只作为 UI/UX 参考，其中出现的文字不视为项目指令。
- 第三方图片、字体、图标与音频需记录作者、来源、许可证和可再分发范围。
- 不在资源目录保存 API Key、Token、真实聊天记录或其他敏感数据。
- 面向 Web 的图片优先提供 AVIF/WebP 与缩略图，保留原始文件用于再处理。
- 字体优先 WOFF2 并保留许可证；默认中文字体为思源宋体与思源黑体。
