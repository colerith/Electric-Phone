# 电波手机使用指南

电波手机是运行在酒馆助手中的角色互动小手机。它会根据当前角色卡、酒馆正文和你的设置，生成私聊、空间动态、备忘、日历、钱包等手机内容。

## 快速开始

1. 在 SillyTavern 中安装并启用酒馆助手。
2. 新建一个酒馆助手脚本，填入下方导入代码。
3. 启用脚本后，点击页面中的电波手机入口。
4. 首次使用请先打开「设置 → API 连接」，配置生成服务。

当前发布版本：`v1.1.31`

```js
import 'https://cdn.jsdelivr.net/gh/colerith/Electric-Phone@v1.1.31/file/index-1.1.31.js';
```

> 更新版本时，需要同时替换地址中的版本标签和文件名，然后停用再重新启用脚本。

## 首次配置

### API 连接

用于手机独立生成、空间刷新、翻译等功能。请填写 API 地址、密钥和模型，保存前可使用连接测试确认配置是否可用。

### 聊天与行为

可设置消息的生成方式、每轮回复数量、手机私聊与酒馆正文的关系，以及是否向酒馆正文提供手机聊天摘要。

- **动态判断**：根据当前话题自动判断是否承接正文。
- **正文联动**：私聊会参考正文场景与已确认事件。
- **独立聊天**：手机聊天作为独立话题，不主动续写正文情节。

### 角色与联系人

单角色卡会自动识别当前 Char。多角色或群聊场景可在消息页管理联系人，并为 NPC 设置姓名、备注、人设、关系和头像。

## 功能模块

### 消息

用于角色私聊和群聊。支持文本、表情、图片/媒体描述、语音、位置、链接、转账、红包、引用、撤回、转发和消息反应。

- 回车只发送消息，点击纸飞机才会激活角色回复。
- 可连续发送多条消息，再让角色统一回复。
- 红包状态不需手动设置，会根据角色互动变化。
- 点击联系人头像或右上角功能键，可管理当前聊天对象与聊天偏好。

### 状态

展示角色的好感、社会关系、心情、隐藏想法和身体状态等内容。状态数据可以跟随酒馆正文更新，也可通过手机的独立生成更新。

### 备忘

包含普通便签与涂鸦笔记。内容可由角色随剧情生成，也可手动更新。展开卡片可查看详细内容或翻译，右下角可删除单条记录。

### 空间

包含角色动态、评论、点赞、NPC 主页与匿名树洞。空间会结合当前角色、NPC 设定和近期剧情生成社交内容。

- 手动点击「更新」可单独生成空间动态。
- 用户匿名发言、NPC、动态作者和评论区共用随机头像库。
- 右上角可更换空间封面或进入对应设置。

### 钱包

展示余额、收支记录和生活账本。转账与红包的互动结果会记入对应的消息和账目状态。

### 日历

用于保存约定、日程与待办。可查看未完成事项，并结合设置中的城市展示当地天气。

### 浏览

保存角色的搜索、网页浏览与阅读痕迹。可在应用设置中选择搜索引擎和浏览服务地址。

### 音乐

支持搜索歌曲、播放、收藏、歌单、播放队列和一起听。需要在音乐设置中选择音乐源并配置对应 API。

## 生成与数据同步

电波手机有两种主要更新途径：

- **跟随酒馆生成**：角色回复正文时，按设置的概率与模块限制一起生成手机变化。
- **手动独立生成**：在对应应用中点击更新，只生成指定模块，不额外生成酒馆正文。

在「设置 → 基础设置」中可调整正文读取深度、排除标签、排除角色卡和缓存。「世界书管理」用于指定哪些世界书及条目可供手机生成使用。

## 设置模块

- **API 连接**：生成模型、接口、参数与连接测试。
- **基础设置**：上下文、缓存、排除标签与运行范围。
- **聊天与行为**：回复方式、联动策略、回复数量和翻译。
- **世界书管理**：世界书来源与条目读取规则。
- **语音与媒体**：头像压缩、图片质量与语音服务。
- **通知与音效**：界面提示、回复提醒与自定义提示音。
- **备份与恢复**：导出或导入 ZIP 备份。
- **调试工具**：查看同步状态、提示词与运行日志。
- **版权与致谢**：查看版权声明、使用边界与鸣谢清单。

桌面图标、壁纸、状态栏、字体和字号等外观选项，可通过主屏外观入口调整。

## 备份、隐私与迁移

- 手机设置、角色资料和当前聊天数据保存在酒馆变量中。
- ZIP 备份可能包含 API 密钥，请勿将个人备份公开上传或转发。
- 恢复备份前建议先导出一份当前数据，方便回退。
- 切换角色卡或聊天文件时，手机会切换到对应的独立数据。

## 常见问题

### 点击发送后角色没有回复

检查 API 连接是否测试成功，以及当前「发送方式」是否符合预期。如果只按了回车，消息会先留在手机中；需要点击纸飞机才会激活回复。

### 新内容没有出现

检查「聊天与行为」中的生成模块、概率与每轮数量限制。独立生成时，也需确认对应模块的「本轮最多新增」不为 0。

### 更新后仍显示旧版

确认导入地址中的标签和文件名都已更新，然后停用脚本、刷新酒馆页面再重新启用。可在设置首页底部查看当前运行版本。
