# Y2K Chat Application

## Overview
The Y2K Chat Application is a modern chat interface that allows users to communicate in real-time. It features a clean design, dynamic message handling, and a user-friendly interface.

## Project Structure
```
y2k-chat-app
├── css
│   └── style.css        # Styles for the chat application
├── js
│   └── main.js         # JavaScript code for handling chat functionality
├── index.html          # Main HTML file for the application
└── README.md           # Documentation for the project
```

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, etc.)
- Basic understanding of HTML, CSS, and JavaScript

### Installation
1. Clone the repository or download the project files.
2. Navigate to the project directory.

### Running the Application
1. Open `index.html` in your web browser.
2. The chat application interface will load, allowing you to start chatting.

### Features
- Real-time messaging
- User-friendly interface
- Responsive design for mobile and desktop

## Usage
- Type your message in the input area and hit "Enter" to send.
- You can also use stickers and media sharing features.
