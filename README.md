# 电波手机使用指南

电波手机是 SillyTavern 中的角色互动手机扩展，生成和展示私聊、群聊、空间动态、备忘、日历、钱包等内容。当前版本 **v1.3.14**，继续依赖酒馆助手 4.x。

## 快速开始

1. 安装并启用酒馆助手。旧用户先导出备份、停用原电波手机脚本，保留其数据。
2. 在酒馆「扩展 → 安装扩展」填写：`https://github.com/colerith/Electric-Phone`。
3. 安装后刷新，从酒馆扩展菜单「电波手机」进入。扩展设置中始终有「打开电波手机 / 重试」入口。
4. 已有服务器与聊天存档继续读取；新用户进入「设置 → API 连接」配置生成服务。

以后从酒馆扩展管理更新并刷新，不再编辑脚本版本地址。不要同时启用旧脚本与扩展。

普通用户不需要运行构建命令，仓库自带 `dist/index.js`。

本版更新：优先修复大存档恢复时的内存峰值和启动超时。冗余备份先读取 1KB 元信息，再下载最新完整存档；同一聊天恢复与同步合并执行，已读快照仅保留全局及当前聊天。解析缓存按聊天读取，统计与清理只读元信息；旧解析缓存自动重建，原始聊天和存档保留。流式生成期间暂停重复全量同步，结束或停止后统一处理；首次恢复网络中断自动重试，大存档读取超时调整为 120 秒。

音乐后端：[Electric-Phone-Music](https://github.com/colerith/Electric-Phone-Music)。安装服务端插件并重启酒馆后，音乐账号自动连接，无需填写三家 API 地址或另开服务进程。仓库提供安装器；首次仍需管理员在酒馆服务器安装。登录、会员和播放权限以音乐平台实际返回为准。

## 首次配置

### API 连接

用于手机独立生成、空间刷新、翻译等功能。请填写 API 地址、密钥和模型，保存前可使用连接测试确认配置是否可用。

### 聊天与行为

可设置消息的生成方式、每轮回复数量、手机私聊与酒馆正文的关系，以及是否向酒馆正文提供手机聊天摘要。

- **动态判断**：根据当前话题自动判断是否承接正文。
- **正文联动**：私聊会参考正文场景与已确认事件。
- **独立聊天**：手机聊天作为独立话题，不主动续写正文情节。

### 角色与联系人

单角色卡会自动识别当前 Char。消息页右上角加号可选择「从角色卡描述导入」，预填当前卡片名称与描述，也可从世界书导入角色。多角色或群聊场景可在消息页管理联系人，并为 NPC 设置姓名、备注、人设、关系和头像。

## 功能模块

### 消息

用于角色私聊和群聊。支持文本、表情、图片/媒体描述、语音、位置、链接、转账、红包、引用、撤回、转发和消息反应。

- 回车只发送消息，点击纸飞机才会激活角色回复。
- 可连续发送多条消息，再让角色统一回复。
- 红包状态不需手动设置，会根据角色互动变化。
- 点击联系人头像或右上角功能键，可管理当前聊天对象与聊天偏好。

六个角色面板（状态、备忘、空间、日历、浏览、音乐）可点击右上角头像切换查看对象。菜单只列出私聊设置中类型为“主要角色”的联系人；NPC 和群聊不会列入。

### 状态

展示角色的好感、社会关系、心情、隐藏想法和身体状态等内容。状态数据可以跟随酒馆正文更新，也可通过手机的独立生成更新。

### 备忘

包含普通便签与涂鸦笔记。内容可由角色随剧情生成，也可手动更新。展开卡片可查看详细内容或翻译，右下角可删除单条记录。在备忘设置中可选择“倒序：最新在前”或“顺序：最新在后”，便签与涂鸦分别排列。

### 空间

包含角色动态、评论、点赞、NPC 主页与匿名树洞。空间会结合当前角色、NPC 设定和近期剧情生成社交内容。

- 手动点击「更新」可单独生成空间动态。
- 用户匿名发言、NPC、动态作者和评论区共用随机头像库。
- 右上角可更换空间封面或进入对应设置。

### 钱包

展示余额、收支记录和生活账本。转账与红包的互动结果会记入对应的消息和账目状态。

### 日历

用于保存约定、日程与待办。可查看未完成事项，并结合设置中的城市展示当地天气。

### 浏览

保存角色的搜索、网页浏览与阅读痕迹。可在应用设置中选择搜索引擎和浏览服务地址。

### 音乐

支持搜索歌曲、播放、收藏、歌单、播放队列和一起听。需要在音乐设置中选择音乐源并配置对应 API。

## 生成与数据同步

电波手机有两种主要更新途径：

- **跟随酒馆生成**：角色回复正文时，按设置的概率与模块限制一起生成手机变化。
- **手动独立生成**：在对应应用中点击更新，只生成指定模块，不额外生成酒馆正文。

在「设置 → 基础设置」中可调整正文读取深度、排除标签、排除角色卡和缓存。「世界书管理」用于指定哪些世界书及条目可供手机生成使用。

## 设置模块

- **API 连接**：生成模型、接口、参数与连接测试。
- **基础设置**：上下文、缓存、排除标签与运行范围。
- **聊天与行为**：回复方式、联动策略、回复数量和翻译。
- **世界书管理**：世界书来源与条目读取规则。
- **语音与媒体**：头像压缩、图片质量与语音服务。
- **通知与音效**：界面提示、回复提醒与自定义提示音。
- **备份与恢复**：可直接全量导出 ZIP，或打开分批导出弹窗按模块勾选。导入时可选择文件中需要的模块，也兼容旧版完整备份。
- **调试工具**：查看同步状态、提示词与运行日志。
- **版权与致谢**：查看版权声明、使用边界与鸣谢清单。

桌面图标、壁纸、状态栏、字体和字号等外观选项，可通过主屏外观入口调整。

纪念日可在「外观」选择绑定的主要角色，设置其独立起始日期；主屏头像与名称固定跟随绑定角色。路人 NPC 和群聊不列入纪念日选项。

## 系统时间

在「设置 → 基础设置 → 系统时间」选择时间来源，点击「保存基础设置」保存。

- **按时区显示真实时间**：默认北京时间（Asia/Shanghai），支持地区时区、自动夏令时和固定 UTC 偏移。
- **自定义日期时间**：指定日期与时间，关闭自动走时时保持静止；开启后按真实经过时长前进。
- **跟随柏宝书时间**：读取摘要页顶部当前“时间”字段，实时监听变化，不自行走时。首次未读到时间时，请打开柏宝书摘要页；关闭面板后可通过新版柏宝书公开接口读取后续更新。旧版无接口时保留当前聊天上次读取的时间。

状态栏、主屏时钟、纪念日和日历的“今天”共用此时间。切换聊天不会沿用其他聊天的柏宝书时间。

## 备份、隐私与迁移

- 手机设置、角色资料和当前聊天数据保存在酒馆变量中。
- ZIP 备份可能包含 API 密钥，请勿将个人备份公开上传或转发。
- 角色设定可合并到当前卡片；聊天记录及应用内容只恢复到原角色卡、原聊天，未勾选模块保持不变。
- 恢复备份前建议先导出一份当前数据，方便回退。
- 切换角色卡或聊天文件时，手机会切换到对应的独立数据。

## 常见问题

### 点击发送后角色没有回复

检查 API 连接是否测试成功，以及当前「发送方式」是否符合预期。如果只按了回车，消息会先留在手机中；需要点击纸飞机才会激活回复。

### 新内容没有出现

检查「聊天与行为」中的生成模块、概率与每轮数量限制。独立生成时，也需确认对应模块的「本轮最多新增」不为 0。

### 更新后仍显示旧版

确认导入地址中的标签和文件名都已更新，然后停用脚本、刷新酒馆页面再重新启用。可在设置首页底部查看当前运行版本。

### 内置头像库

头像资源在 `assets/avatars/v1/`，单独按需加载，不写入聊天存档或主脚本。素材由 DiceBear 生成，包含插画、像素、表情及几何等风格，不是 Pinterest 图片或 Discord 官方头像。来源、作者、许可和调整说明见 [素材署名](assets/avatars/v1/ATTRIBUTION.md)；逐图种子与校验和见 `manifest.json`。复现：`cd tools/avatars && npm ci && node generate.mjs ../../assets/avatars/v1`。v1 文件名和分配顺序固定，后续扩充应新增版本目录。
