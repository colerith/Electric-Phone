# 电波手机组件样式规范

适用于新增及调整的手机组件。现有页面逐步按此规范收敛；不要为了统一字号批量改动聊天正文、用户自定义字体和艺术字。以“打开入口方式”的左侧标签、右侧控件布局为设置行基准。

## 文字层级

下表为手机内部 CSS 基准尺寸，不是截图放大后的像素值。使用 `--wave-ui-font`；随用户文字缩放采用 `calc(基准字号 * var(--wave-font-scale, 1))`，同一文字只缩放一次。

| 角色 | 基准字号 / 字重 | 行高 | 对齐与颜色 |
| --- | --- | --- | --- |
| 页面标题 | 17px / 600 | 1.4–1.5 | 居中，仅导航栏标题；正文区域标题左对齐；主文字色 |
| 独立详情大标题 | 21px / 600 | 1.4 | 左对齐；仅确有主次层级时使用 |
| 卡片、分区标题 | 15px / 600 | 1.5 | 左对齐，主文字色；不额外加渐变、全大写或大字距 |
| 设置项名称、列表主标题 | 13px / 600 | 1.5 | 左对齐，主文字色；单独标签与带说明的标签必须同级 |
| 输入值、选择值、按钮文字、正文 | 13px / 400–500 | 1.5–1.7 | 输入与选择值左对齐，按钮文字居中 |
| 帮助说明、副标题 | 11px / 400 | 1.65 | 左对齐，次文字色；允许自然换行 |
| 时间、来源、计数等元信息 | 10px / 400 | 1.5 | 按所属内容对齐；不得作为设置项名称字号 |
| 温度、金额等展示数字 | 24–46px / 500–600 | 1.1–1.3 | 仅用于核心数据，数字可采用等宽数字 |

设置行已提供 `--settings-label-size`、`--settings-label-weight`、`--settings-help-size`。外观页的语言、辅助触控和打开入口行共用这些变量。`strong` 继承父标签字号，不能因多包一层标签而缩小；描述文字单独指定帮助字号。

## 组件对齐与间距

- 设置行采用左右布局：左侧名称和说明，右侧开关、选择器或操作按钮。行内垂直居中，间距 12–16px；文字区 `min-width: 0`，开关禁止压缩。
- 有说明时，名称与说明左边缘对齐，相隔 4–6px。说明较长自然换行，不与右侧控件重叠。
- 窄屏允许控件换至下一行，但仍左对齐；不得默认变为整块居中排版。需要时减少并列控件或改成整行操作。
- 按钮文字与图标用 `inline-flex` 居中，间距 8px；常规按钮高度至少 36px，主要操作建议 42px。独立“恢复默认”操作可居中，文字字段不跟随居中。
- 相邻设置行用 1px 分割线，颜色使用 `--settings-line` 或 `--wave-line`；避免深色模式中的纯白横线。卡片边框与内部线应比正文弱。
- 标签、输入值、按钮文字不得用负边距或强制固定高度掩盖对齐问题；长中文和中英混排都应保持可读。

## 颜色语义

| 类型 | 设置组件变量 | 用法 |
| --- | --- | --- |
| 主文字 | `--settings-text` / `--wave-ink` | 标题、标签、正文；名称本身通常不染蓝 |
| 次文字 | `--settings-muted` / `--wave-muted` | 说明、来源、时间；不可过淡到难以阅读 |
| 交互强调 | `--settings-accent` / `--wave-blue` | 可点击操作、选中状态、焦点；避免把所有标题都设为强调色 |
| 普通控件底色 | `--settings-control` / `--wave-tint` | 次要按钮、输入区域；深色模式禁止固定白底 |
| 卡片底色 | `--wave-card` | 内容容器；与页面底色保持可区分的层次 |
| 边框、分割线 | `--settings-line` / `--wave-line` | 低对比辅助结构，不与文字抢视觉重点 |

危险操作用现有删除组件的危险色；重要日程可用柔和粉色底、边框和标题区别。状态含义必须同时通过文字、图标或形状表达，不能只靠颜色。正常文本对比度目标至少 4.5:1，大字与必要控件边界至少 3:1；浅色、深色都要分别检查。禁用状态保持可辨识，配合 `disabled`，不等同于普通辅助说明。

## 实现与验收

1. 样式限定在 `#wave-phone-script-root .wave-device` 与具体组件内，不写全局 `label`、`span`、`strong`、`button` 字号覆盖。
2. 先使用主题变量；组件特有的深色覆盖集中在 `styles/base/night-components.scss`。不要用硬编码白底、黑字兼容所有主题。
3. 旧 `styles/base/style.scss` 中 `.settings-card label > span` 存在 9px 强制规则。修改对应组件时用有范围的语义规则覆盖，不能继续复制该小字规则。仅在处理这类历史覆盖时使用必要的 `!important`，注明原因。
4. 检查浅色、深色、320–390px 窄屏及放大文字：标签同级同字号，说明不抢标题，按钮文字不截断，左右对齐稳定。
5. 检查默认、选中、禁用、悬停及键盘焦点；焦点轮廓应清晰，不能只靠文字变色。
6. 日志只描述本次真正调整的组件，不声称所有历史页面已全面统一。
